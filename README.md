# Geo Control Room

Web app statica per un quiz geografico su mappa satellitare.

## Come provarla

Apri `index.html` in un browser moderno.

## Come pubblicarla

Carica tutta questa cartella su un hosting statico:

- GitHub Pages
- Netlify
- Vercel
- Cloudflare Pages
- hosting web aziendale

Il file di ingresso e `index.html`.

## Note

- La mappa usa Esri World Imagery tramite tile pubblici:
  `https://server.arcgisonline.com/arcgis/rest/services/World_Imagery/MapServer`
- Non c'e backend.
- Non ci sono cookie, login o analytics.
- Il punteggio vive solo nella sessione del browser.
- L'interfaccia include selezione lingua: italiano, inglese, spagnolo, tedesco, francese, cinese e russo.
- Anche i nomi dei luoghi e delle aree geografiche vengono localizzati nella lingua selezionata.
